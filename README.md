# 🎮 Word Master Challenge

**Word Master Challenge** is a fun and interactive word-scrambling game built with **Python and Tkinter**. Players have to unscramble words within a time limit, earn points, maintain streaks, and progress through **10 difficulty levels**.

## ✨ Features

* 🔤 Randomly scrambled words
* 🎯 10 progressive difficulty levels
* ⏱️ 18-second timer for each word
* ⭐ Score and streak system
* 💡 3 hints available
* ⏭️ Skip option with score penalty
* 📊 Level progress bar
* 🏆 Final champion message after completing all levels
* ⌨️ Press **Enter** to submit an answer

## 🛠️ Technologies Used

* **Python**
* **Tkinter**
* **Random Module**

## 🎮 How to Play

1. Run the Python program.
2. A scrambled word will appear on the screen.
3. Enter the correct word in the input box.
4. Click **Submit** or press **Enter**.
5. Correct answers increase your score and streak.
6. Wrong answers reduce your score and reset the streak.
7. Use **Hint** when you need help.
8. Use **Skip** to move to another word with a penalty.
9. Complete all 10 levels to become the **Word Master Champion!**

## 📈 Scoring

* Correct answer: **+10 points + streak bonus**
* Wrong answer: **-2 points**
* Skip: **-5 points**
* Time out: **-5 points**
* Correct answers increase your streak.

## 🚀 Installation & Run

Make sure Python is installed on your computer.

```bash
git clone https://github.com/your-username/word-master-challenge.git
cd word-master-challenge
python game.py
```

No external packages are required because the game uses Python's built-in **Tkinter** and **random** modules.
